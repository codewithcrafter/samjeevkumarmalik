## Frequently Asked Questions

### Q1: Do you provide only Figma design files or do you also code the frontend?

We provide both! If you only need UI/UX architecture, we deliver production-ready Figma design systems with auto-layout, design tokens, and clickable prototypes. However, because Sanjeev Kumar Malik is also a Senior Full-Stack Architect, we frequently engineer the complete frontend implementation (HTML/CSS/TypeScript or React/Next.js), guaranteeing zero discrepancy between the design and the final live product.

### Q2: What is the difference between visual graphic design and UX architecture?

Graphic design focuses purely on how something looks (colors, illustrations, fonts). UX architecture focuses on how something works: information hierarchy, user task completion speed, reducing cognitive friction, handling system errors, mobile thumb ergonomics, and ensuring data flows logically. A visually pretty site that confuses users will fail to generate revenue; UX architecture solves the business problem first.

### Q3: How do you ensure designs are accessible (WCAG 2.2 AA compliant) for all users?

We test every color combination against the WCAG 2.2 minimum contrast threshold of 4.5:1 for standard text and 3:1 for large text and interactive components. We specify high-visibility keyboard focus rings, define ARIA roles for screen readers, ensure interactive touch targets are at least 44x44 pixels, and verify that layouts adapt smoothly when users increase default browser font sizes.

### Q4: Can you audit and redesign our existing SaaS dashboard without breaking backend APIs?

Yes. We specialize in non-destructive UX refactoring. We audit your existing API endpoints, data models, and user roles to ensure that our new UI components map cleanly to your existing backend payload structures, allowing your engineering team to modernize the user experience without rewriting their database or backend logic.

### Q5: What tools do you use for UI/UX design and developer handoff?

We work primarily in Figma using modern features including Auto-Layout 5.0, Component Variants, and Local Variables (Tokens). We export design tokens in JSON format and generate matching CSS custom properties stylesheets, making developer adoption frictionless across React, Vue, or native HTML environments.

### Q6: How long does a typical UI/UX design sprint take?

A focused landing page or marketing website UI/UX sprint typically spans 1 to 2 weeks. A comprehensive multi-screen SaaS web application or customer dashboard design sprint typically takes 3 to 4 weeks, including user journey mapping, design system creation, high-fidelity screen designs, and interactive prototyping.
